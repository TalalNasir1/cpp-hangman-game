# Hangman Game in C++

A basic console-based Hangman game developed using C++ during my first
semester of Computer Science.

This was my first programming project and helped me understand fundamental
programming concepts such as variables, loops, conditional statements,
functions and strings.

## About the Game

Hangman is a word-guessing game in which the player tries to discover a
hidden word by entering one letter at a time.

The player has a limited number of incorrect attempts. The game ends when
the player guesses the complete word or uses all available attempts.

## Features

- Console-based user interface
- Hidden word represented using Staric
- Letter-by-letter guessing
- Correct and incorrect guess detection
- Limited number of attempts
- Previously guessed letters tracking
- Win and loss messages

## Technologies Used

- C++
- Standard C++ Library
- Console/Terminal
- Visual Studio Code

## Programming Concepts Practised

- Variables and data types
- Input and output
- `if` and `else` statements
- Loops
- Functions
- Strings
- Arrays or vectors
- Basic game logic

## How to Run

### Requirements

- A C++ compiler such as GCC
- Visual Studio Code, Code::Blocks or another C++ IDE

### Compile the Program

g++ src/main.cpp -o hangman
